Use case: ui-mockup

Asset type: OpenFilm landing-page first viewport, desktop web, landscape

Primary request: A high-fidelity, shippable OpenFilm photo editor landing page built as an early one-bit desktop interface, with the working editor as the hero.

Structure: One large overlapping application window demonstrates the real local workflow with choose photo, crop selection, a compact strip of looks, before/after, and export. The first action and window hierarchy remain immediate.

System: Black and white pixels only; ordered stipple dither stands in for gray; active selection inverts. One-pixel window chrome, title bars, 32-pixel icons, and marching ants create the state language.

Constraints: No invented claims, pricing, testimonials, color, gradients, generic rounded SaaS cards, unrelated logos, device frame, or watermark. Practical control sizing and the user’s photograph remain primary.
