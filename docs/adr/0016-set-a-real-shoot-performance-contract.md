# Set a real-shoot performance contract

The first release targets a 2,000-photo Library of 45-megapixel JPEGs. The first internal baseline is a 16 GB Apple M4 MacBook Air, which does not establish support for other devices. Acceptance requires p95 selection feedback within 50 ms, other interactions within 100 ms, an interactive visible grid within five seconds of permission, 60 fps visible-thumbnail navigation with a 30 fps floor, and no eager full-resolution decoding. A generated stress corpus covers scale, while a rights-cleared camera corpus covers metadata, similarity, sharpness, and color. OpenFilm makes no public performance claim until the harness, both corpora, and measurements exist.
