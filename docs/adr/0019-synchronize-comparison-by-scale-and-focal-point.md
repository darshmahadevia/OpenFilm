# Synchronize Comparison by scale and focal point

Comparison shows the current Edits for two to four Photograph records through the shared renderer. It synchronizes zoom scale and a focal point expressed in uncropped Source-photograph coordinates, then maps and clamps that point through each Edit's geometry. Fit mode is shared, 100 percent means one source pixel per CSS pixel when memory permits, a pane may be temporarily unlinked, and a shared hold control reveals every Source photograph without its Look or geometry.
